# Phase 26 — 暗色星空主题（Starry Sky Theme）

> 目标：把全局氛围配色从「青色 HUD 深空」替换为「暗色星空」——星点加密分级、银河带、星云云团、行星弧光；
> 保持全部设计令牌（`--background: #05070e` 等）与 UI 组件不变，确保对比度与 34 项冒烟测试零回归。
> 策略：氛围层（ Atmosphere ）整体重铸，令牌层与组件层不动。

---

## 1. 现状走查（改动前）

| 层 | 现状 | 问题 |
|---|---|---|
| 基底 | `--background: #05070e` + 顶部青色洗光 | 基底正确，但洗光是青色 HUD 气质，非夜空 |
| 星点 | canvas 50–160 个点，单一半径 0.4–1.55，透明度 0.22–0.7 | 太稀、无大小分级、无亮星光晕、无聚集感 |
| 极光 | 2 个 radial 团（青 / 橙），52–64s 漂移 | 橙色团与「夜空」语义不和；缺乏星云的蓝紫层次 |
| 网格 | 22px 青色点阵 + 底部透视网格流向观众 | Tron 透视地面属于 HUD 语言，与星空主题冲突 |
| 流星 | 8–14s 一颗，青色拖尾 | 保留（星空标志性元素） |
| 指针 | 840px 青色聚光灯跟随 | 保留，降透明度避免与星点争辉 |

**结论**：星空只做到了「几个白点」，缺少夜空的三个决定性特征——**星的密度与分级**、**星云的色团层次**、**天穹/天线的空间感**。

## 2. 设计方案

### 2.1 视觉（自底向上）

1. **天穹洗光**：body 顶部洗光由纯青改为靛蓝→青的极淡双向渐变（`rgba(124,108,240,.07)` → `rgba(92,225,255,.03)`），像夜空本身的天光。
2. **星云 ×3**（替代原 aurora ×2，纯 CSS、仅 transform 动画、70–110s 极慢漂移）：
   - 靛蓝 `rgba(99,102,241,.06)` 左上大云
   - 紫罗兰 `rgba(167,139,250,.05)` 右中
   - 青 `rgba(34,211,238,.04)` 右下（银河核心方向）
3. **星点重铸**（canvas，分级 + 光晕 + 银河带）：
   - 三级星等：暗星 65%（r .3–.7，α .15–.35）、常星 28%（r .5–1.1，α .35–.7）、亮星 7%（r 1.1–1.8，α .8–1，**带径向光晕精灵**）
   - 银河带：40% 星点沿 −28° 对角线高斯聚集，更小更密，偏白
   - 色调：白 91% / 冰蓝 5% / 暖白 4%（点缀，不做成银河摄影的过饱和）
   - 密度按面积缩放：桌面 ≤300，触屏 ×0.5；DPR ≤2
   - 光晕用离屏 sprite 预渲染一次，`drawImage` 绘制——零每帧渐变开销
4. **行星弧光**（替代底部透视网格）：300vmax 椭圆暗面（近黑蓝径向）+ 顶部 1.5px 青色大气弧光 + 弧上方的 haze 辉光——「站在行星边缘仰望星空」的空间锚点。保留 `pointer: coarse` 与 `max-width: 640px` 降级。
5. **点阵网格**：透明度 5.5% → 4%，青色改靛蓝染色，退居到最底层不再与星点争辉。
6. **指针聚光灯**：透明度 8.5% → 6%，新增星点 canvas 整体 ±8px 视差（帧内缓动），纵深感。

### 2.2 性能与可访问性（硬约束）

- 持续动画全部走 `transform`/`opacity`（合成器线程）；canvas 每帧仅 `fill`/`drawImage`
- `prefers-reduced-motion`：星点静态绘制（twinkle=1、不漂移、不发流星）、星云/聚光灯静止
- 标签页隐藏时停 rAF（已有 `visibilitychange` 逻辑保留）
- 文字对比度不受影响：氛围层 `aria-hidden`、`-z-10`、透明度 ≤6%；面板/正文令牌零改动，WCAG AA 保持
- 冒烟测试断言的 `rgb(5,7,14)` 基底色不变 → 测试零回归

### 2.3 不动的东西（范围控制）

- 全部设计令牌（surface/ink/signal/radius/shadow/motion）
- 全部组件类（.card/.btn-*/…）与 24 个路由的信息架构
- 流星、聚光灯、grain、glass、HUD 滚动条

## 4. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 星点过密影响内容可读性 | 中 | 星点最大 α 1.0 但 r ≤1.8px 且集中在无文字的天区密度；面板不透明区域不受影响；截图验收 |
| 行星弧光在矮视口裁切异常 | 低 | vmax 单位 + `overflow:hidden` + 640px 断点降高；截图双端验收 |
| canvas 密度上升致低端机掉帧 | 中 | 面积缩放上限 300；触屏减半；sprite 光晕；reduced-motion 直停 |
| reduced-motion 清单漏项 | 低 | 同步维护 `@media (prefers-reduced-motion)` 选择器清单，逐条核对 |
| Playwright 断言旧背景色 | 无 | `--background` 不变，断言天然通过 |

## 5. 验收标准

- typecheck / lint / build 全绿
- Playwright 34/34 通过（背景断言不变）
- 截图人工验收：星空密度、星云色团、行星弧光、流星均在；375px 无裁切异常
- Lighthouse 移动性能不劣化（氛围层无新增 JS 主线程负担：单 rAF + 合成器动画）
